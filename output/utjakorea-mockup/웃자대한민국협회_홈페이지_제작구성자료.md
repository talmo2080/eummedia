## 1. 사이트 목표

웃자대한민국협회의 활동과 정기 프로그램을 처음 방문한 사람도 30초 안에 이해하고, 바로 참여하거나 문의할 수 있는 공식 홈페이지를 만듭니다.

핵심 방문자:

- 매주 프로그램에 처음 참여하려는 주민
- 웃음·치유·문화 프로그램을 찾는 중장년층
- 협회 활동과 연혁을 확인하려는 기관·단체
- 행사·공연·힐링테라피 협업을 문의하려는 기관

핵심 행동:

1. 이번 주 프로그램 일정과 장소 확인
2. 참가비와 예약 필요 여부 확인
3. 전화·이메일·카카오톡으로 문의
4. 협회 활동과 지난 기록 확인

- 질문 범위: 일정, 장소, 참가비, 참여 방법, 전화 문의

- 운영체제의 움직임 감소 설정에서는 CSS 애니메이션을 줄이거나 정지합니다.
- 모바일에서는 화면 가장자리와 버튼을 가리지 않는 크기로 축소합니다.

## 6. 페이지 2: 협회 이야기 `/about`

### 목적

협회가 누구이며 어떤 활동을 얼마나 지속해 왔는지를 한 페이지에서 신뢰감 있게 보여줍니다.

### 섹션 순서

#### 6-1. 페이지 히어로

- 라벨 또는 상단 메뉴: `협회 이야기`
- 제목: `협회 이야기`
- 설명 예시: `웃자대한민국협회는 봉숭아학당 문화혁신학교 산하 비영리 단체입니다. 서울 관악구에서 12년 동안 웃음으로 사람을 이어왔습니다.`
- 배경: 따뜻한 크림색

#### 6-2. 설립 취지

- 작은 라벨: `설립 취지`
- 제목: `웃음으로 시민의 삶을 행복하게, 웃음으로 서울을 활기찬 문화도시로`
- 본문: 웃음·문화예술·창조적인 콘텐츠, 시민 누구나 일상에서 웃음과 행복을 누릴 수 있는 문화 환경을 만든다는 방향을 설명합니다.
- 강조 문장은 골드로 표시하되, 한 문단 안에 너무 많은 색을 사용하지 않습니다.

#### 6-3. 함께 만든 시간

- 라벨: `함께 만든 시간`
- 숫자: `12년`
- 핵심 문구: `624회, 한 주도 거르지 않고`
- 설명: 봉숭아학당 문화혁신학교와 함께 웃음 나눔과 식사 무료 나눔을 이어온 활동을 설명합니다.
- 사진: `twelve-years-photo.png` 또는 협회가 최종 제공하는 12년 활동 사진
- 숫자 `624회`와 활동 기간은 발행 시점에 맞춰 운영자가 갱신할 수 있게 데이터화합니다.

#### 6-4. 협회가 하는 일

번호 카드 5개:

1. 시민 참여형 문화예술 교육 및 캠페인
2. 찾아가는 웃음 문화 공연 및 나눔
3. 페스티벌·전시·포럼의 기획과 운영
4. 문화예술 기관·단체·예술가와의 교류·협력
5. 그 밖의 공익 목적 부대사업

각 카드에는 제목과 한 줄 설명을 넣고, 모바일에서는 세로 목록으로 쌓습니다.

#### 6-5. 함께 만드는 사람들

- 인물 카드 2개 이상
- 시안 기준: `성창운`, `오행자`
- 각 카드: 사진, 이름, 역할, 2~3줄 소개
- 인물·직함·소개 문구는 실제 운영자 확인 후 확정
- 오행자 교수의 말 카드:
  - `발산은 치유다.`
  - `치료는 의사가 해주지만, 치유는 내가 하는 것.`

#### 6-6. 함께하는 곳

기관 카드 예시:

- 이음미디어
- 봉숭아학당 문화혁신학교
- 이음평생교육원
- 산들소리

각 카드에 기관명, 짧은 설명, 홈페이지 또는 자세히 보기 링크를 넣습니다.

#### 6-7. 협회의 기록

- 연도별 타임라인 또는 기록 카드
- 카드 구성: 대표 이미지, 날짜, 행사명, 2~4줄 설명
- 최신 기록이 먼저 보이도록 정렬
- 카드 클릭 시 상세 기록 또는 사진 갤러리로 이동

## 14. 기능 요구사항

- 모든 헤더 메뉴와 CTA는 실제 경로로 이동
- 전화번호는 모바일에서 누르면 전화 앱이 열리는 `tel:` 링크
- 이메일은 `mailto:` 링크
- 네이버 지도·카카오맵 버튼은 최종 주소 기준으로 생성
- 이미지에는 의미 있는 한국어 대체 텍스트 제공
- 외부 링크는 새 창 여부를 일관되게 적용
- 갤러리는 썸네일 클릭 시 큰 이미지와 닫기 버튼 제공
- AI 질문 버튼은 모바일 하단 네비게이션과 겹치지 않게 표시
- 페이지 로딩 시 이미지가 레이아웃을 밀어내지 않도록 비율 또는 고정 높이 지정
- 운영자 확인 전인 정보에는 임시값을 하드코딩하지 않도록 표시

## 15. 반응형 기준

### 모바일

- 헤더는 햄버거 메뉴로 전환
- 2열 카드와 정보 영역은 1열
- 대표 이미지가 텍스트보다 먼저 또는 자연스러운 순서로 배치
- CTA 버튼은 화면 폭에 맞춰 충분한 터치 영역 확보
- 본문 좌우 여백 20px
- 스마일 챗봇은 폭 72~96px 정도로 축소
- 긴 주소·전화번호·이메일은 잘리지 않고 줄바꿈

### 데스크톱

- 콘텐츠 최대 폭 1120~1200px
- 대표 이미지와 설명을 1:1 또는 45:55로 배치
- 기록·활동 카드는 3~4열까지 사용
- 여백을 충분히 두되, 정보가 지나치게 아래로 흩어지지 않게 구성

## 16. 접근성·검색 기본

- 페이지마다 고유한 `<title>`과 설명 메타 태그
- 한 페이지에 H1은 하나
- H2/H3 계층을 시각적 크기만으로 만들지 않고 의미 있는 태그 사용
- 이미지 대체 텍스트 제공
- 키보드로 메뉴·버튼·갤러리·AI 대화창 조작 가능
- 글자와 배경의 대비 확보
- 움직이는 스마일은 `prefers-reduced-motion`을 존중
- 전화·주소·일정은 이미지 안에만 넣지 말고 실제 텍스트로 제공
- 행사 정보 변경 시 `lastmod`와 구조화된 페이지 정보 갱신
